# Kiral — High-Precision Chess Review & AI Platform

Kiral — высокоточный профессиональный инструмент для анализа шахматных партий, игры против регулируемого ИИ Stockfish, локальных матчей 1 на 1 и решения тактических задач с обучающими объяснениями.

Разработано в строгой утилитарной эстетике (Monochrome Dark, 1px border-driven UI, zero AI clichés) с нулевой блокировкой интерфейса благодаря исполнению движка Stockfish в фоновом Web Worker.

---

## Возможности

- **Интерактивный разбор (Game Review)**:
  - Загрузка любых PGN/FEN с автоматическим вычислением CAPS Accuracy (точности) для белых и черных.
  - Классификация каждого полухода по формуле сигмоиды Expected Points (Win%):
    - `!!` Блестящий (Brilliant)
    - `!` Отличный (Great)
    - `★` Лучший (Best)
    - `✓` Прекрасный (Excellent)
    - `○` Хороший (Good)
    - `📖` Книжный/Теория (Book)
    - `?!` Неточность (Inaccuracy)
    - `?` Ошибка (Mistake)
    - `??` Зевок (Blunder)
    - `✕` Упущенный шанс (Miss)
  - Векторный график оценки партии (Eval Graph) с синхронизацией клика по ходам.
  - Вертикальная шкала оценки (24px Eval Bar) с поддержкой переворачивания доски.
  - Инспектор лучших линий движка (MultiPV 2, глубина, оценка в сантипешках / мат).

- **Игра против ИИ (Stockfish 10 UCI)**:
  - Выбор цвета (Белые / Черные).
  - 6 уровней сложности с регулировкой UCI `Skill Level` (0–20) и глубины:
    - **Новичок** (~600 ELO, depth 2, Skill 0)
    - **Любитель** (~1000 ELO, depth 4, Skill 3)
    - **Быстрый** (~1300 ELO, depth 6, Skill 6)
    - **Клубный** (~1600 ELO, depth 10, Skill 12)
    - **Эксперт** (~2000 ELO, depth 14, Skill 17)
    - **Гроссмейстер** (~2500 ELO, depth 18, Skill 20)
  - 1.5-секундный фокус на статусе хода с русскоязычным синтезом речи (Web Speech API).
  - Индикация шаха (подсветка клетки атакуемого короля и бейдж `ШАХ`).

- **Тактические задачи и обучение (Puzzles)**:
  - Подборка разнообразных тактических мотивов (Слабость 1-й горизонтали, Вилка, Спёртый мат, Связка, Отвлечение, Мат Морфи, Мат Анастасии, Вскрытый шах).
  - Интерактивная проверка ходов с автоматическими ответами компьютера.
  - Пошаговые подсказки и подробные тактические объяснения.
  - Фильтрация по сложности (Легкие, Средние, Сложные) и счетчик решенных задач.

- **Игра 1 на 1 (Два игрока / PvP)**:
  - Локальная игра на одной доске с очередностью ходов, оценкой ходов движком и ведением протокола партии.

## Стек технологий

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS.
- **Шахматная логика**: `chess.js`, `react-chessboard`.
- **Шахматный движок**: Stockfish 10 (Web Worker / asm.js / WebAssembly) с очередью асинхронных задач и UCI-протоколом.
- **Аудио & Синтез**: Web Audio API (звуки ходов, взятий, шаха, зевков) + Web Speech API (голосовые комментарии на русском).
- **Иконки**: `lucide-react`.
